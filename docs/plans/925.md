# Plan: #925 volume-pool tenant moves

Objective: move a tenant's closed replica directory from its source pool
mount to its destination pool mount, node by node, behind a move journal
`__sys:volumepool/moves/{tenant}`, cut over by one assignment write
(docs/decisions/volume-pool-tenant-moves.md; Q1-Q10 decided by convention,
ruling 109).

## Slices

1. Built (sr925a). Node-step primitive, unwired. `pkg/volume/move_copy.go`:
   `CopyTree`, `BuildManifest`, `VerifyCopy`, `Manifest`, `ManifestEntry`;
   `*MoveStepError` and `*ManifestMismatchError` in `catalog_errors.go`.
   Implements Q2 A (file copy of the closed replica directory, fsync files
   and directories, source kept) and Q4 A (relative path, size, SHA-256
   manifest built while copying, recomputed from the destination, equality
   required). Tests (`move_copy_test.go`, TempDir trees): round trip,
   refusals (path rules, overlap, symlink, pipe), cancelled context, each
   mismatch reason, no absolute path in any message.
2. Built (sr925b). Node step on this node's pools:
   `seal.BarrierRegistry.RunMoveCopyStep` (pkg/seal/move_step.go), unwired;
   decisions recorded by convention.
3. Built (sr925c). Journal record and catalog admit, unwired:
   `Catalog.AdmitMove` (one transaction reserving the tenant's bytes on the
   destination and writing the journal in state `admitted`), `MoveKey`,
   `MoveAdmitRequest`, the new `Move` fields, `LockableProvider`; Q3 (ready
   on every replica node), Q5 record, Q9 (Lockable to plain needs the flag)
   and Q10 refusals (`Release`, `AdjustReservation`, a second admit,
   `DeletePool` of either pool) with `*MoveConflictError`. Tests:
   `catalog_move_test.go`.
4. `MoveTenant`/`GetMove` on the journal, tenant-kind and
   `AllowedVolumePools` checks in the tenant layer, the Q9 audit record.
5. Journal transitions and the reconciler driving the node step (Q6),
   reopen-and-catch-up verify.
6. Cut over, retire, cancel, abort (Q7, Q8); errclass rows.
7. Transports and CLI verbs, with CLI multi-transport E2E and features.mk.

## Out of scope for slices 1-3

Journal transitions after admit, reconciler, `MoveTenant`/`GetMove`
change, Q9 audit, errclass, transports, CLI, config keys. The primitive
never deletes: a partial destination is removed through
`seal.BarrierRegistry.RequireInsideLocalPool`.
