# Plan: #925 volume-pool tenant moves

Objective: move a tenant's closed replica directory from its source pool
mount to its destination pool mount, node by node, behind a move journal
`__sys:volumepool/moves/{tenant}`, cut over by one assignment write
(docs/decisions/volume-pool-tenant-moves.md; Q1-Q8 and Q10 adopted, ruling
1115; Q9 with the owner, owner queue 287, refused outright meanwhile).

## Slices

1. Built (sr925a). Node-step primitive, unwired. `pkg/volume/move_copy.go`:
   `CopyTree`, `BuildManifest`, `VerifyCopy`, `Manifest`, `ManifestEntry`;
   `*MoveStepError` and `*ManifestMismatchError` in `catalog_errors.go`.
   Q2 A and Q4 A. Tests: `move_copy_test.go`.
2. Built (sr925b). Node step on this node's pools:
   `seal.BarrierRegistry.RunMoveCopyStep` (pkg/seal/move_step.go), unwired.
3. Built (sr925c). Journal record and catalog admit, unwired:
   `Catalog.AdmitMove`, `MoveKey`, `MoveAdmitRequest`, `LockableProvider`;
   Q3, Q5 record, Q9 and Q10 refusals. Q9 was a consent flag; sr925f
   replaced it with the outright refusal. Tests: `catalog_move_test.go`.
4. Built (sr925d). `Catalog.MoveTenant` and `GetMove` through the
   `volume.MoveAdmission` (`tenant.TenantService.AdmitTenantMove`) and
   `volume.MoveStartAuditor` (`service.NewVolumeMoveAudit`,
   `volume_pool.move_start`, no flag since sr925f) seams. Tests:
   `catalog_move_test.go`, `pkg/tenant/volume_move_test.go`,
   `pkg/service/volume_move_audit_test.go`.
5a. Built (sr925f). Step transitions `GrantMoveStep`/`CompleteMoveStep`/
   `FailMoveStep`, states copying/copied/aborting, `MoveReconciler.
   ReconcileOnce` over the `MoveStepRunner` seam; Q9 interim refusal
   `*MoveToUnencryptedPoolError`, consent flag removed. Tests:
   `move_journal_test.go`, `move_reconciler_test.go`.
5b. The node-side `MoveStepRunner` (close stores, `RunMoveCopyStep`, reopen
   from the destination, catch-up verify).
6. Cut over (which must also update `tenant.TenantInfo.VolumePool`),
   retire, cancel, abort (Q7, Q8); errclass rows.
7. Composition wiring (the lifecycle replica-node source,
   `SetMoveAdmission`, `SetMoveStartAuditor`, the reconciler's leader
   schedule and transition audit), transports and CLI verbs, with CLI
   multi-transport E2E and features.mk.

## Out of scope for slices 1-5a

Composition wiring of any move seam, the node-side step runner, the
reconciler's schedule, cut over, errclass rows for the new move errors,
transports, CLI, config keys. The primitive never deletes: a partial
destination is removed through `seal.BarrierRegistry.RequireInsideLocalPool`.
