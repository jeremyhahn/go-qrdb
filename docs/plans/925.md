# Plan: #925 volume-pool tenant moves

Objective: move a tenant's closed replica directory from its source pool
mount to its destination pool mount, node by node, behind a move journal
`__sys:volumepool/moves/{tenant}`, cut over by one assignment write
(docs/decisions/volume-pool-tenant-moves.md, status PROPOSED, Q1-Q10
unruled).

## Slices

1. Node-step primitive, unwired (this slice). `pkg/volume/move_copy.go`:
   `CopyTree`, `BuildManifest`, `VerifyCopy`, `Manifest`, `ManifestEntry`;
   `*MoveStepError` and `*ManifestMismatchError` in `catalog_errors.go`.
   Implements Q2 A (file copy of the closed replica directory, fsync files
   and directories, source kept) and Q4 A (relative path, size, SHA-256
   manifest built while copying, recomputed from the destination, equality
   required). Tests (`move_copy_test.go`, TempDir trees): round trip,
   refusals (path rules, overlap, symlink, pipe), cancelled context, each
   mismatch reason, no absolute path in any message. Docs:
   engineering.md exported surface, error table, test strategy;
   architecture.md one sentence.
2. After the owner rules Q1-Q10: move journal and state machine (Q5).
3. Admit (Q3, Q9, Q10) and `MoveTenant`/`GetMove` on the catalog.
4. Reconciler driving the per-node step (Q6), reopen-and-catch-up verify.
5. Cut over, retire, cancel, abort (Q7, Q8); errclass rows.
6. Transports and CLI verbs, with CLI multi-transport E2E and features.mk.

## Out of scope for slice 1

Journal, reconciler, `MoveTenant` change, errclass, transports, CLI,
config keys. The primitive never deletes: a partial destination is the
future caller's to remove through `seal.BarrierRegistry.RequireInsideLocalPool`.
