# Plan: #925 volume-pool tenant moves

Objective: move a tenant's closed replica directory from its source pool
mount to its destination pool mount, node by node, behind a move journal
`__sys:volumepool/moves/{tenant}`, cut over by one assignment write
(docs/decisions/volume-pool-tenant-moves.md; Q1-Q8 and Q10 adopted, ruling
1115; Q9 with the owner, owner queue 287, refused outright meanwhile).

## Slices

   `CopyTree`, `BuildManifest`, `VerifyCopy`, `Manifest`, `ManifestEntry`;
   `*MoveStepError` and `*ManifestMismatchError` in `catalog_errors.go`.
   Q2 A and Q4 A. Tests: `move_copy_test.go`.

   `volume.MoveStartAuditor` (`service.NewVolumeMoveAudit`,
   `volume_pool.move_start`, no flag since sr925f) seams. Tests:
   `catalog_move_test.go`, `pkg/tenant/volume_move_test.go`,

5a. Built (sr925f). Step transitions `GrantMoveStep`/`CompleteMoveStep`/

   ReconcileOnce` over the `MoveStepRunner` seam; Q9 interim refusal
   `*MoveToUnencryptedPoolError`, consent flag removed. Tests:
   `move_journal_test.go`, `move_reconciler_test.go`.

   Built (sr925j): the path-leak fix in `checkRootPath`, the leader/node

## Out of scope for slices 1-6a

Composition wiring of any move seam, the node-side step runner, the
reconciler's schedule, transports, CLI, config keys. The primitive never deletes: a partial
destination is removed through `seal.BarrierRegistry.RequireInsideLocalPool`.
