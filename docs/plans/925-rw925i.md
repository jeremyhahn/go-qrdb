Codex round 4 (review at 25cd2b4307) P1 2, and the typed-nil membership gap.

- **P1 2 status.** The safe failure/cancel transition landed in rw925e:
  `settleAndRelease` counts each failed settle with `Catalog.FailSettleStep`,
  and past the attempt bound, or on a recorded cancel, it aborts a copy settle
  to `aborting` with the node copied. This lane adds the end-to-end coverage
  over the real `volume.Catalog`, `volume.MoveReconciler` and
  `seal.MoveStepRunner`, and makes the rollback safe. Before this change,
  `copyBack` removed the source before copying the destination back. Now
  it copies the destination into `<path>.copyback` in the source pool,
  verifies it there, and only then removes the source and renames the
  staging directory into place. A failed copy or verify removes only the
  staging directory. A rerun removes a stale staging directory first and
  treats a missing source as removed. The node stays copied, because a
  shard may have acknowledged entries from the destination.

## rw925j

- **Fixed: copy-back onto a mount-point source.** The rw925i known limit
  (a tenant source directory that is a mount point made the abort retry
  until an operator unmounted it) is gone. When renaming the staged tree onto
  the source fails with EBUSY or EXDEV, `copyBack` keeps the emptied root and
  swaps its contents: it copies the verified staging tree into
  `.qrdb-copyback` inside the mount, verifies it, moves each child up with
  `fsync.Rename`, syncs the root and removes both staging directories. A
  rerun after a partial swap empties the root and redoes it.
- **Tests.** `TestMoveStepRunner_CopyBackOntoMountPointSource`
  (pkg/seal/move_runner_test.go) models the mount through the registry's
  `DirectoryRemover` and a rename seam on `MoveStepRunner` (EBUSY onto the
  root, EXDEV across it): clean swap, rerun after a failed partial swap, and
  a rerun after success. `TestVolumePool_CLI_MoveTenant_PerProtocol` is rerun
  unchanged; the CLI surface did not change.
- **CHANGELOG line (to paste):** `- Volume pools: aborting a tenant move
  whose source directory is a mount point now restores the source in place
  instead of retrying until the directory is unmounted (#925).`
