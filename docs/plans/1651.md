## iam1651e

SPEC item (5) authz-object-owner: an object-owner ABAC condition beside the
tenant check `OwnTenant`, so go-xkms drops its own owner check.

- Go rule: `pkg/auth/object_owner.go` (`WithResourceOwner`,
  `ResourceOwnerFromContext`, `OwnObject`, `ObjectOwnerDeniedError`).
- ABAC: `pkg/auth/abac/types.go` (`ResourceOwnerContextKey`),
  `decorator.go` (owner into the check request), `parser.go`
  (`subject.owns_resource`, `ownsResource`).
- SDK: `sdk/go/types_object_owner.go` (`sdk.OwnObject`,
  `sdk.WithResourceOwner`, `sdk.ResourceOwnerFromContext`,
  `sdk.ObjectOwnerDeniedError`, `sdk.ABACResourceOwnerContextKey`).
- Tests: `pkg/auth/object_owner_test.go`,
  `pkg/auth/abac/parser_test.go` `TestConditionParser_OwnsResource`,
  `pkg/auth/abac/object_owner_test.go`, `sdk/go/types_object_owner_test.go`,
  CLI e2e `TestABACPolicy_CLI_ObjectOwnerCondition_PerProtocol`.
- Docs: `docs/identity-rbac/engineering.md`, `user.md`, `cli.md`,
  `CHANGELOG.md`.

Convention decisions:

- The condition is a built-in boolean subject field `subject.owns_resource`,
  beside `subject.authenticated` and `subject.mfa_verified`: true only when
  the request carries a non-empty resource owner equal to a non-empty subject
  id, false otherwise (fail closed when the owner is absent or the subject id
  is empty). `compareEqual` is unchanged; a hand-written
  `resource.owner == subject.id` is not a safe owner test.
- The owner is carried server-side through the context, the way the target
  tenant is: `auth.WithResourceOwner(ctx, ownerID)`, set by the embedder's
  store before it asks the PDP, never from a caller-written request field.
- The Go rule is `auth.OwnObject(ctx, owner, op string) error`, OwnTenant's
  shape, in `pkg/auth` because it needs the identity, which `pkg/tenant`
  cannot import. Its refusal unwraps to `auth.ErrUnauthorized`
  (PermissionDenied) with no errclass edit.
- No wire field is added: go-qrdb has no owner-bearing object on its
  transports; the over-the-wire surface is the stored policy that uses the
  condition.
