# #1735: keep the command-conflict wire codec internal

## Objective

Codex P1 on #1706: `sdk/go/transport` exported `CommandConflictError`,
`ReasonCommandConflict` and `CommandConflictFromMetadata`, which the SPEC
embedder-seams row does not name. Ruling 109 + most-pure option: the wire
encoding is internal. The public face of the refusal stays a
`*dberrors.QRDBError{Code: ErrConflict}` reached through `errors.As`.

## Module layout

`sdk/go` is its own module (`github.com/jeremyhahn/go-qrdb/sdk/go`), so a
`sdk/go/internal/...` package is not importable from `pkg/api/errclass`.
The root module's `internal/` is: Go's internal rule is by import path, and
every `sdk/go` package path sits under `github.com/jeremyhahn/go-qrdb/`
(precedent: `sdk/go` already imports `internal/netport`).

## Slice 1 (this lane)

- New `internal/wireconflict`: `Reason`, `Metadata(message)`, `Message(md)`.
  Test: metadata round trip, missing key.
- `sdk/go/transport`: delete the three exported symbols; the refusal decode
  rebuilds an unexported `commandConflictError` whose `As` yields the
  `QRDBError` with `ErrConflict`. Test: `RefusalError` round trip yields
  `errors.As *dberrors.QRDBError` Code `ErrConflict`, non-retryable.
- `pkg/api/errclass`: encode through `wireconflict`. Test: reason + message,
  and the client rebuild of the same refusal is `ErrConflict`.

## Out of scope

docs/SPEC.md, pm/rows.md, go.mod requires, compat aliases, other error
types. Docs naming `service.CommandConflictError` stay as they are.
