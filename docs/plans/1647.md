# Plan: #1647 SealStoreClient on every transport (docs/18 V12, SealStore half)

#1660 shipped the PermissionClient half. This row ships the SealStore half.

## Objective

`transport.SealStoreClient` answers on all six transports (embedded, grpc,
rest, quic, unix, mcp) instead of embedded only, gated server-side by
`permission.SealStoreManage` (`seal:store_manage`, ScopeCross, SO-exclusive),
the same permission the embedded transport checks.

## Slices

1. Shared remote client: `transport.SealStoreEndpoints` +
   `NewRemoteSealStoreClient` (`sdk/go/transport/seal_store_remote.go`),
   mirroring `permission_remote.go`. Refuses nil requests and empty names
   before the wire. Test: `seal_store_remote_test.go` (round trip, refusal
   without a wire call).
2. Server endpoints, one per listener, each gated by `seal:store_manage`:
   gRPC RPCs in `qrdb.proto` (regenerated), REST `/v1/seal-store/...`, QUIC
   `sealstore.*` methods, MCP `qrdb_seal_store_*` tools; the server holds a
   `*seal.SealStore` over the node barrier.
3. Client wiring on grpc, rest, quic, unix and mcp with
   `var _ transport.SealStoreClient` assertions.
4. E2E on each of the six transports (no sleeps); docs: SPEC.md SDK row,
   `sdk/go/doc.go`, identity-rbac and barrier-seal engineering docs (the
   "no network route" statements change).
5. CLI: `qrdb seal-store` verbs, CLI E2E on every network transport and an
   embedded CLI test (fs1647a).

## Findings on the base

- `Client.SealStore()` already goes through `capability[T]`.
- `TestClient_CapabilityAccessors_ReturnTheTransport` fails untagged only on
  its `SQL` case (the embedded SQLProvider is `qrdb_sql`-tagged); with the
  Makefile's `test-sdk` tags it passes.
- The docs and `pkg/permission` state the seal store has no network route by
  design (node-local, in-process embedders only). Exposing it is an
  architecture change; the coordinator's resume order directs it.

## Out of scope

- CustodianGroups()/Shares() beyond the one SPEC.md line.
- New permissions: the routes reuse `seal:store_manage`.
