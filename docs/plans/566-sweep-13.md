# #566 sleep sweep 13 (rw566s)

Sweep 9 kept two `time.Sleep` rows of its "Remaining time.Sleep inventory"
(`docs/plans/566-sweep-9.md`) as injected store latency: `slowSyncSM.Update`'s
sync delay in `pkg/backend` and `slowGetStore.Get`'s read delay in
`pkg/trustanchor`. Both are in-process fakes, and nothing their tests drive
starts a goroutine outside the test or blocks on anything that is not durably
blocking (`LocalBackend` starts no goroutines; `KVRegistry` over the memory
store blocks only on the injected sleep). This sweep runs every test that
uses them inside a `synctest.Test` bubble, so the injected latency is fake
time: each sleep advances the bubble's clock and none waits in real time.
Line numbers in the table are the lines before the sweep. No production code
changes, and no behaviour loses its test.

| File | Line | Replaced by / kept and why |
