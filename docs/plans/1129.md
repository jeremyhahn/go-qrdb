4. Codex round 2 (PR #1579):
   a. pkg/firstboot Initialize binds a generated admin certificate only after
      the system SO enrollment, so an SO failure commits no binding and the

      `TestInitialize_SOFailureKeepsGeneratedAdminKeyRecoverable`.

      `TestBootPendingRecordStore_NoSOIssuedNeedsNoQuorum`.

      commit is durable; test: the marker survives a crash after init.
