# #566 sleep sweep 11 (rw566p)

Sweep 9 left every remaining `time.Sleep` as a kept row of its "Remaining
time.Sleep inventory" (`docs/plans/566-sweep-9.md`), and every one of those
rows still slept in real time. Sweep 10 introduced the `synctest.Test` form
(`pkg/discovery/multicast_test.go`). This sweep moves the kept windows whose
code is in-process only (no sockets, no subprocesses, no signals) in
`pkg/sql/internal/sessionguard` and `pkg/service` into `synctest.Test` bubbles:
every goroutine the test relies on (the guard's `watchProbe` and
`watchAdmission`, `ReclaimSweeper.Run`) starts inside the bubble, each
`time.Sleep` is a fake-clock advance, and `synctest.Wait()` proves every
goroutine has settled before an assertion that something did not happen. The
`t.Cleanup(g.Stop)` registered by `newStarted` inside the bubble runs inside
it, so the guard's loops end before the bubble exits. Line numbers in the table
are the lines before the sweep. No production code changes, and no behaviour
loses its test.

| File | Line | Replaced by / kept and why |
|------|------|----------------------------|
| pkg/sql/internal/sessionguard/sessionguard_test.go | 180 | `TestStreamEndClosesOnlyItsTenantsSessions`: body in `synctest.Test`; after `waitClosed(t, acme)` the 20ms window is `time.Sleep(20 * time.Millisecond)` inside the bubble (twenty fake 1ms guard ticks) followed by `synctest.Wait()` before asserting globex was not closed; `waitClosed`'s `time.After(5s)` arm is a fake-time guard and stays |
| pkg/sql/internal/sessionguard/sessionguard_test.go | 206 | `TestRelease_ForgetsTheSession`: body in `synctest.Test`; after `streams.EndAll` and `p.sealed.Store(true)` the window is `time.Sleep(20 * time.Millisecond)` inside the bubble (twenty fake probe ticks, so `watchProbe` reads the sealed probe and runs `endAll`) followed by `synctest.Wait()` before asserting the released session was not closed |

| pkg/service/reclaim_job_test.go | 786 | `TestReclaimSweeper_SetStoreResolverIsRaceFreeWithRun`: body in `synctest.Test`; the 100ms context and the 1ms pacing `time.Sleep(time.Millisecond)` are fake time, so Run ticks every fake millisecond against the resolver swaps; the interleaving `-race` checks stays and the run takes no wall time (Run's sweep path over the fake catalog store blocks on nothing that is not durably blocking) |
