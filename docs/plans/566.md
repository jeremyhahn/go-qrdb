Without `qrdb_vector`, pkg/vector/hnsw compiles only its stubs, which refuse every index ("vector support not compiled"), so these pkg/service tests failed untagged; CI and the Makefile build with the tag, so they still run there. No test changed.

- vector_restart_test.go (whole file tagged): TestVectorService_RestartPreservesConfiguredMetric and TestVectorService_SnapshotInstallPreservesConfiguredMetric search a reopened real index; its helper `newRestartVectorStorage` moved to the untagged vector_geometry_refusal_test.go, which also uses it.
- vector_metric_index_test.go (new, tagged) holds, moved unchanged: TestNewNamespaceIndex_BuildsForStoredMetric and TestVecCreateNamespace_ManhattanAccepted (from vector_metric_test.go: build an HNSW index); TestNewNamespaceIndex_FlatSearchesExactly, TestNewNamespaceIndex_IVFRefusesSearchUntilTrained and TestNewNamespaceIndex_ManhattanOnLiveTypes (from vector_index_kind_test.go: the namespace index is built through the hnsw stubs too); TestVectorService_SupportedStoredGeometryStillSearches (from vector_geometry_refusal_test.go: searches a real index); TestPerformIndexRebuild_PagesEveryVectorOnce (from vector_list_cursor_test.go: rebuilds a real index).
- hard_confined_watch_test.go:TestHardConfinedWatch_WatchEntityTypeFilterGoroutineExitsOnContextDone: an empty entityTypeChan proved only that the forwarder took the event, not that it reached `select { case out <- ev: case <-ctx.Done(): }`, so cancel() plus the test's receive could make both cases ready and a correct forwarder could send. It now runs in `synctest.Test`: Wait (durably blocked on the send), cancel, Wait (it took ctx.Done and closed out), then ch must read closed.
