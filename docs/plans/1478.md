# #1478 part 4 — time series, seal and ceremony, cluster operations

## Objective

Close docs/gui/coverage-matrix.md gap groups 9 (Time series), 10 (Seal and
ceremony) and 11 (Cluster operations): every listed SDK method and display
is reachable from the UI and proven by a mocked Playwright spec, with a
DOM-tier round trip against a live qrdbd where the matrix asks for one.
The work is replayed from the reference lane (lane/gui1478a), these groups
only.

## Slices

1. Time series (group 9): TimeSeriesView gains batch write, aggregate,
   rich query and retention cards; the single-point Write takes a point.
   Tests: e2e/timeseries-advanced, timeseries-ops, timeseries-write-point;
   e2e/dom/timeseries-advanced-roundtrip.
2. Seal and ceremony (group 10): SealManager shows every cluster seal field
   and the cluster migration progress, unseals the cluster, changes the
   passphrase, and has a ceremony card (state, SPKI pin, sign CSR).
   Tests: e2e/admin-seal; e2e/dom/cluster-seal-roundtrip,
   cluster-seal-active-roundtrip, ceremony-passphrase-roundtrip.
3. Cluster operations (group 11): Cluster mints a join token and reads and
   sets node compaction; RebalancePanel shows a shard's stats.
   Tests: e2e/admin-cluster, rebalance-panel, web-mode-cluster,
   web-mode-cluster-detection; e2e/dom/cluster-topology,
   rebalance-roundtrip, node-compaction-roundtrip, join-token-roundtrip.
4. Matrix: these groups' operation and display rows verified, the groups
   marked covered, the summary counts recomputed for them.

## Smallest pieces taken from other groups

- DOM fixtures (cluster passphrase, per-test client certificate through
  the Vite proxy) the DOM specs import.
- A single-node Raft server is "raft" (the Cluster view mints its first
  join token there); isMultiNodeServer keeps the wizard's replica and
  Raft steps for multi-node servers.
- REST SDK wire fixes the views need: shard stats path, the time-series
  aggregate, rich query and retention routes and point encoding.
- Database wizard create no longer sends engine and mode, which the
  server's strict decoder refuses (main's own DOM timeseries spec failed).
