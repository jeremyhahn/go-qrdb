# Plan: SPEC row strict-tenant-isolation (#1565)

## Objective

Ship the SPEC row `strict-tenant-isolation` (docs/SPEC.md): each strict
tenant gets a home store holding every record the platform does not need to
place, route, size or retire it, with per-node tenant barrier init. The row's
one PR folds the earlier per-item PRs and marks the row shipped in
docs/SPEC.md.
