## fx1542u

Done:

- `TestWebTransport_RESTLayersRefuseBeforeTheHandler` (`pkg/api/rest`): a
  started server, an authenticated session dialled over real QUIC. A closed
  sealed window and an awaited admin credential each answer `503`; with a
  client limiter of burst 1 the first dial answers `200` and reaches the
  handler, the second answers `429`. No refused dial establishes a session or
  runs the handler. Every layer already sits in the HTTP/3 chain: no defect,
  no change to `webtransport.go` or `server.go`.
- `TestWebTransport_TCPListenersDoNotSpeakWebTransport` (`pkg/api/rest`): an
  authenticated `CONNECT` to the session path on the TCP listener answers
  `400` over HTTP/1.1 (the route's not-HTTP/3 refusal) and `404` over HTTP/2,
  and the handler runs 0 times. net/http's HTTP/2 client refuses a `:protocol`
  pseudo-header, so the HTTP/2 case is a plain `CONNECT`, which carries no
  `:path` and matches no route.
- `docs/api-server/api.md`: a "Refused before the upgrade" row in the
  WebTransport sessions table; `CHANGELOG.md`: one Unreleased line.

Not in this lane: owner approval of the SPEC row (Tenant); a qrdbd flag for the
