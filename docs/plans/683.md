# Plan: strict-tenant-isolation phase 7, PN-3 (#683)

## Objective

PN-3 (platform custody): a node without a cluster identity (no CA pool, node
certificate or signing key) refuses a platform-custody raft tenant and claims
nothing for a barrier or volume one. Prove it with tests and record it in
`docs/multi-tenancy/engineering.md`.

## Slices

1. **No-identity refusal (this slice).** `wirePlatformInit`
   (`pkg/server/lifecycle/barrier_init.go`) wires no signer without the
   node's cluster identity; `TenantService.claimPlatformInit` with no signer
   refuses a raft tenant (the claim book requires a statement) and undoes the
   create, and claims nothing for a barrier or volume tenant.
   Tests (already on main, kept as the proof):
   - `TestWirePlatformInit_WiresNothingWithoutItsParts`
     (`pkg/server/lifecycle/platform_init_test.go`): no CA pool, no node
     identity, no node certificate, or a key that cannot sign wires no signer
     and no platform anchor.
   - `TestCreateTenant_ARefusedPlatformClaimUndoesTheCreate/no platform signer/raft`
     (`pkg/tenant/platform_init_test.go`): `*InitStatementRequiredError`, no
     tenant record, no registry entry.
   - `TestCreateTenant_NoPlatformClaim/no platform signer/{barrier,volume}`:
     the create succeeds, no claim, the signer is never asked.
   Docs: the PN-3 paragraph's "Not yet built" names only the serving-set
   check.
2. **Serving-set check (next slice).** The serving-set check before a shell
   is registered; needs `pkg/placement/serving_set.go` from draft PR #1494.

## Out of scope

- The serving-set half of PN-3 until #1494 lands.
- docs/SPEC.md, go.mod, other PN work packages.
