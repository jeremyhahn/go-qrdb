### PR #1657 Lint Gates red at 90c1fe8dbb (rw979a)

- Cause: commit 9efe25e60 ("build: commit the go.sum lines go build -mod=mod
  writes") added 171 `/go.mod`-only hashes for modules outside the build graph
  (atomicgo.dev/*, cloud.google.com/go/aiplatform, gorm.io/*, golang.org/x/perf
  and others). `make lint-gates` runs `check-mod-tidy`
  (scripts/check-mod-tidy.sh), which runs `GOWORK=off go mod tidy -diff` per
  module and fails when tidy would change `go.sum`; tidy removes those lines,
  so Lint Gates was red and the CI Gate aggregate with it.
- Fix: commit "build: restore the tidy go.sum; go mod tidy removes the lines
  9efe25e60 added (#1657)" writes `go.sum` byte-identical to 1ff960ca2's (the
  merge of main into the row, parent of 9efe25e60). `go.mod` is unchanged.
- Acceptance results:
  - Before the fix, `GOWORK=off go mod tidy -diff` in the repo root exited 1
    and printed a diff removing the added lines (e.g. gorm.io/*,
    mvdan.cc/sh/v3, sigs.k8s.io/yaml `/go.mod` hashes).
  - After the fix, `GOWORK=off go mod tidy -diff` in the repo root exits 0 and
    prints nothing; it could run in the lane (the module cache served it).
  - `git diff 1ff960ca2 HEAD -- go.sum` prints nothing.
  - `GOFLAGS=-mod=readonly go list -deps -test -tags=codec_json,raft ./...`
    succeeds: the build needs none of the removed lines.
  - `go.mod` and `go.sum` unchanged by the runs.
