# Plan: multi-model databases (#923)

## Objective

Ship the approved `docs/databases/` design ("Target" sections of
`docs/databases/engineering.md`): every database is a binding resolved from
the catalog, created through the node's `database_defaults`, with the
acceptance items of "Target: acceptance" proven by unit tests and the CLI
multi-protocol E2E (REST, gRPC, QUIC, MCP, Unix).

Already on main: binding resolution and the `database_defaults` key with Raft
state storage on every create transport (#1526; the fold refs
`multi-model-databases/lane/x1526b` and `x1526c` are fully merged).

## Slices, in order

1. **Node defaults: SQL creates** (done, PR #1673).
   - `pkg/sql/provider` `CreateDatabase` names no backend: both the
     DatabaseService path and the system-session manager path record the
     node's `database_defaults` backend, else the run mode's (raft / pebble).
   - `cmd/qrdbd` `sqlDatabaseConfig` no longer derives a backend from `--sm`;
     `Manager.Provision` fills the defaults once and records them.
   - Tests: provider unit tests (defaults backend, raft run mode, standalone
     run mode, on both create paths); `cmd/qrdbd` `sqlDatabaseConfig` carries
     no backend for any `--sm`, provision records the default in the catalog;
     E2E `test/integration/database_defaults_sql_cli_test.go`: SQL-created
     (MySQL and PostgreSQL wire) and `--sql-database` databases report the
     node default on every transport, and the raft run-mode default with
     `--sm memory`.
   - Docs: architecture.md current state, user/cli/configuration wording,
     CHANGELOG, SPEC row 176 status "in progress".
2. **Node defaults: remove the node-wide override** (this slice, PR #1673).
   The standalone node's one local store (until slice 3) takes its backend
   from `storage.backend` (pebble when empty), never from `databases[0]`:
   `sdk/go/node` `resolveBackend`, `cmd/qrdbd` standalone start,
   `pkg/config/mode.go` at-rest report. A `databases[]` entry keeps its own
   backend in the catalog. `StandaloneRaftBackendError` goes (Validate
   already refuses `storage.backend: raft`).
   - Tests: `resolveBackend` storage.backend cases plus a memory entry that

     `TestStandaloneMode_NodeStoreFromStorageBackend_PerProtocol` (file
