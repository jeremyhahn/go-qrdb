# #566 sleep sweep 14 (rw566t)

Sweep 9 kept two in-process fake latencies as real-time sleeps: the
cluster-proof soak harness's fake store (`opDelay` in `fakeConn`, sweep 8's
"injected fake-store latency") and the 50us window in the etcd serial-stream
detector (`overlapDetectingStream.Send`). Both are fakes with no sockets,
subprocesses or signals, so the tests that reach them now run inside
`synctest.Test` bubbles (the form of sweeps 10-12): the latency is fake time,
and a soak Run/Main over `fakeKV` paces its 200-300ms workload on the bubble's
clock with no real time passing. `soak.Run` paces itself only on
`time.Now`/`time.Since`/`time.After`/`time.NewTicker` and its fakes dial
nothing, so a whole Run fits a bubble; the options, and so the bundle under the
outer `t.TempDir`, are built outside the bubble so the bundle outlives it and
`Check` runs outside. One half stays real: `serialWatchStream` serialises Sends
with a `sync.Mutex`, and a goroutine waiting on a mutex is not durably blocked,
so a bubble's clock could not advance past one holder's sleep while the other
senders queue. Line numbers in the table are the lines before the sweep. No
production code changes, and no behaviour loses its test.
