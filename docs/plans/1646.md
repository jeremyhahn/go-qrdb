# Row 1646: codec delete (go-codec owns serialization)

Objective (issue #1646, docs/18 V30, docs/00 L1/L2): go-codec owns the
serialization formats. No file outside go-codec's module imports msgpack,
yaml.v3 or bson for (de)serialization, except where go-codec lacks the API.

## Slices 1-2 (done)

- `pkg/codec` deleted; vector commands, results, stored values and snapshots,
  batch import and CLI output encode through go-codec msgpack/yaml (#1662,
  folded into #1705). Codex approved #1662 in round 5 at 29ec5957c4, no
  findings.

fxamacker/cbor stay required by the gap sites).

Owner: whether #1646 closes with these gaps open, or after go-codec adds them.
