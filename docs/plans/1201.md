# Plan: #1201 scheduled credential rotation

## Objective

A named `barrier` credential can carry a rotation policy (enabled, interval,
retain_versions). Every qrdbd node runs the due policies on a ticker, the
cluster rotates each credential once per interval, and operators set and read
policies, and settle node-local migration conflicts, on every transport.

## Slices, in order

1. **Part 1, store and service** (merged into the stack): rotation policies,
   claim-by-CAS, guarded staged rotation, retention cleanup and `RotateDue`
   on the tenant's replicated credential store. Tests: `pkg/credentials`
   rotation, claim lease, concurrent pass and retention cases.
2. **Part 1, proto** (#1549): qrdb.proto messages and RPCs for rotation and
   delegation policy. Tests: gRPC permission and UNIMPLEMENTED cases, the
   coverage double.
3. **Part 2, scheduler** (#1552): `pkg/server` runs `CredentialRotateDue` on
   `seal.credential_rotation_check_period` (default 1m), skips a pass while
   sealed, never overlaps passes. Both qrdbd servers (the started node and the
   sealed-window listener) get the configured period. Tests: scheduler unit
   tests, config default/override/invalid tests.
4. **Part 2, verbs** (#1552): rotation-policy set/get and migration-conflict
   list/resolve on REST, gRPC, QUIC and MCP; the REST SDK transport. Tests:
   handler tests per transport, the escaped REST name segment, mapping guards.
5. **Part 2, docs** (#1552): configuration key, API verbs, the scheduler in
   the credentials architecture and engineering docs, the extension seam.

## Out of scope

- A built-in `RotationValueSource`: qrdbd ships none; a due rotation fails
  with `ErrNoRotationValueSource` until an embedder injects one.
- A scheduler in the `qrdb` desktop embedded mode: it builds no
  `pkg/server`, so its policies are stored but not run (documented).
- `qrdb credential rotation-policy` CLI verbs and the gRPC/QUIC/Unix SDK
  transports for the new verbs: a later slice of #1201.
- Tenant delegation policy RPCs: they stay UNIMPLEMENTED (#1187).
