# #566 sleep sweep 12 (rw566q)

Sweep 9 left every remaining `time.Sleep` as a kept row of its "Remaining
time.Sleep inventory" (`docs/plans/566-sweep-9.md`). Sweep 11 moved the
in-process windows of `pkg/sql/internal/sessionguard` and `pkg/service` into
`synctest.Test` bubbles. This sweep does the same for the in-process lease
tests of `sdk/go`: the lease there is all fakes (`acquireLease` over
`newCoordinator` with `fakeKV` and `fakeLease`, whose `KeepAlive` blocks on a
channel), so each test runs in a `synctest.Test` bubble, the lease monitor's
timers run on the fake clock, and every deadline the tests assert is the exact
instant the deadline logic produces (`sdk/go/coordination.go` monitor, `Renew`,
`Done`) rather than a wall-clock range. The cleanup `blockedRenewal` registers
inside the bubble releases the held keepalive and the lease, so every goroutine
the lease started ends before the bubble does. The `cmd/qrdbd` port-hold test
uses real sockets, so it stays out of a bubble and waits instead on the
guard's observed poll count. Line numbers in the table are the lines before
the sweep. No production code changes, and no behaviour loses its test.
