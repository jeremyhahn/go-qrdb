# Plan: row 1650, object-storage backup destinations

Objective: a `backup.destination` configuration block (an `ObjstoreConfig`:
provider, settings, credentials by file) names the go-objstore provider that
backups are written to and restored from, for `qrdbd` and for the embedded Go
SDK node. MinIO is provider `s3` with an endpoint (ruling 1243). The embedder
imports no go-objstore path. `--backup-dir` stays the file-engine repository;
the two are exclusive.

## Slices (lane rw1650w1)

1. pkg/config: `Config.Backup.Destination *ObjstoreConfig`, validated
   (provider required, credentials pair). Test: `backup_destination_test.go`.
2. pkg/server/lifecycle: `OpenBackupDestination` (no data-dir default for
   `path`), `BackupDestinationError`. Test: `backup_destination_test.go`.

   `BackupDestinationConflictError`; inline credential refused under
   `backup.destination.settings`. Test: `backup_store_test.go`.

   disaster recovery from it, conflict refuses boot.
   Test: `test/integration/backup_destination_cli_test.go`.
5. sdk/go/node: constructors open `cfg.Backup.Destination` into the backup
   sink; conflict with `WithBackupSink`; store closed in `Close`.
   Test: `sdk/go/node/backup_destination_test.go`.
6. Docs: backup-restore user/cli/architecture/engineering, storage-engines.
